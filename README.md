# 領土戦記 — Territory War

古地図（羊皮紙）風のマップ上で、NPCの国々が勝手に領土を奪い合う様子を**眺めるだけ**の観戦ゲームです。
ブラウザだけで動きます（ビルド不要・依存ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くか、GitHub Pages で公開された URL にアクセスするだけ。

| 操作 | 内容 |
| --- | --- |
| ドラッグ / ホイール / ピンチ | 地図の移動・拡大縮小 |
| Space / 1〜7 | 一時停止 / 速度 (x½・1・2・4・8・16・32、初期はx1) |
| 国をクリック | 国情報（領土・兵力・同盟・戦争・安定度・歴史） |
| 神の手 | ☠️疫病 / 🌋天災 / ✨祝福 / 🔥反乱扇動 |

## 主な仕組み

- **地図**: ランダム大陸（シード指定で再現可）、地球、大陸エディタで自作した地図
- **大陸エディタ**: 陸と海を描くだけ。山・丘・森・砂漠・ツンドラ・川・都市は自動生成。首都位置の指定、ブラウザ保存、JSON 書き出し/読み込みに対応
- **国**: 2〜30か国。国名・都市名はファンタジー風に自動生成
- **領土の取り合い**: 国境が少しずつ動く「浸食」＋ 軍団が行軍・会戦・攻城する「侵攻」の両方
- **地形効果**: 山・丘・森は防御有利で進軍が遅い、川は渡りにくい、軍は船で海を越える
- **外交**: 宣戦布告・同盟・参戦・停戦・裏切り
- **都市・首都**: 都市が兵力を生み、首都が落ちると遷都して国が大きく揺らぐ
- **発展と文化**: 都市が平和に発展すると施設（農地・市場・城壁・学院・大聖堂・大図書館）が建ち、文化点が貯まって文化の時代（草創期〜栄華期）が進む。時代が進むほど兵の質・収入・安定度が上がり、文化の劣る隣国の国境を少しずつ同化する。占領・戦争・天災で発展は失われる
- **反乱・独立**: 大きくなりすぎた国、首都から遠い都市、征服されたばかりの土地で反乱が起き、旧国が復興することも。歴史は終わりません
- **軍団**: 旗持ちと兵士の群れで表示（兵数に応じて兵士が増減）。名前付きの**将軍**が率い、戦果で「歴戦の」「百戦錬磨の」「常勝の」「不敗の」「城落としの」などの称号を得る。将軍は戦死・引退し、名将一覧と歴史書の「名将列伝」に残る
- **会戦**: 敵軍と出会うと戦場が固定され、布陣→射撃戦→白兵戦→追撃と進む。士気が尽きるか兵が4分の1を切った側が潰走し、騎兵の多い勝者ほど追撃で大損害を与える。近くの軍は援軍として加わり（援軍で形勢逆転も）、森・丘・山で待ち構えた軍は伏兵として奇襲する。海上では海戦となり、敗れた艦隊は沈む
- **兵種と相性**: 歩兵・騎兵・弓兵・攻城兵器。騎兵は弓兵・攻城兵器に強く歩兵に弱い、歩兵は騎兵に強い、弓兵は歩兵に強い。騎兵は平原で強く森・山で弱い。国ごとに地形で決まる特色兵（駱駝騎兵・長弓兵・重装歩兵・狼騎兵・海兵・重騎兵）、文化を極めた国には魔導兵・竜騎士。兵士の絵も兵種ごとに描き分け
- **戦記**: 会戦の上に戦況ゲージ（兵力と士気）。進行中の会戦・古戦場・年代記をクリックすると、両軍の将軍・兵力・損害・編成・勝敗の決め手・戦いの経過をまとめた戦記が読める
- **兵糧攻め・降伏**: 包囲された都市は兵糧が減り、尽きると降伏する。兵力が足りない軍は強攻せず包囲を続け、包囲された都市には近くの軍が救援に向かう
- **攻城と市街戦**: 攻囲中の都市には煙・投石・守備兵、城壁が崩れると炎上して**市街戦**に
- **砦・要塞**: 国境の要衝（山・丘・川・街道）に築かれ、周囲は浸食されず、敵軍は落とすまで先へ進めない
- **作戦**: 宣戦時に「北方侵攻作戦」「○○攻略作戦」「紅蓮作戦」などを発動し、大きな作戦矢印が地図に描かれる。目標を落とすと作戦成功
- **古戦場**: 大会戦の跡に剣の印と「○○の戦い（年）」が刻まれる
- **世界自然遺産**: 大瀑布・天を衝く霊峰・千年の神木・鏡の湖・水晶の大洞窟・黄金の砂丘・火の山・極光の氷原が地形に合わせてランダムに現れ、都市と同じように奪い合える。持つ国にボーナス
- **世界の脅威**: およそ100年に1度、魔王軍・古竜・不死の軍勢・氷の女王（冬が広がり凍った土地では人口が減り進軍が止まる）・深海の侵略者（海の門から艦隊が港町を襲う）・邪神の教団（各地の都市で狂信者が蜂起する）のいずれかが出現。全国停戦はせず、諸国は互いの戦争を続けながら（兵の質+0.15・収入+25%で）脅威にも立ち向かう。拠点陥落や古竜撃破で討伐となり、英雄の国と将軍の名が残る。神の手の「⚠️脅威」で好きな場所に呼び出すこともできる（同時に1つまで）
- **対覇権の大同盟**: 一国が大陸の3割を超えて突出すると、周辺国が大同盟を結んで一斉に宣戦する
- **海を越えた戦争**: 時代が進むと、港から海を越えて届く国とも戦争を始め、大艦隊で遠征する
- **世界の驚異**: 天空の大灯台・黄金の大神殿・叡智の大図書院・不落の大城塞・天空の庭園・巨神像・星詠みの塔・千夜の大市場。文化の進んだ国が建設を競い、完成した国だけが効果を得る。都市を占領すると驚異ごと奪え、戦火や天災で遺跡になると再建できる
- **道**: 軍がよく通る場所に 小道→街道→大街道 が育ち、進軍が速くなり（街道には橋も架かる）、沿道の都市が栄える。使われない道は荒れて消える
- **実況モード** 🎙: 宣戦・陥落・大軍の集結・首都の攻囲・勢力図のまとめなどを実況テロップでわかりやすく解説（ON/OFF可）。**自動カメラ** 🎥 で注目の場所へ自動移動
- **歴史書** 📖: 時代ごとの章立て（建国の時代、○○の覇権、動乱の時代…）、大国の興亡、世界の驚異、吟遊詩人の歌をまとめた本をゲーム内で読める
- **吟遊詩人**: 大会戦・王都陥落・大国の滅亡・驚異の完成などの名場面を短い詩にして残す
- **表示**: 年代記ログ、勢力ランキング、領土シェア推移グラフ、地図上の国名ラベル、前線・進軍矢印
- **BGM**: WebAudio でその場で生成する、ゆったりしたファンタジー風の音楽（パッド・ハープのアルペジオ・笛の旋律・残響）。毎回少しずつ違う旋律になり、戦争中の国が多いと暗めの和音進行に変わる
- **効果音**: WebAudio による合成音。ハ長調ペンタトニックの協和音のみで構成し、音が重ならないよう間引き（🔊でON/OFF）
- 🔊 ボタンで BGM と効果音を個別に ON/OFF・音量調整（設定はブラウザに保存）。画面を一度タップ/クリックすると音が鳴り始めます（iPhone はマナーモード解除が必要な場合あり）

### スマホ

- **縦画面**: 下部のタブ（勢力・年代記・推移・国情報）を押すと情報シートが開き、同じタブをもう一度押すと閉じます。速度ボタンは「x1」を押すごとに切り替わります
- **横画面**: 神の手は左に縦並び、情報パネルは ☰ で右側に開閉します
- 地図をタップするとその場所の情報を数秒表示。＋／－／⤢ ボタンで拡大・縮小・全体表示。画面を回転すると自動で地図を合わせ直します

URL の `#map=random&seed=xxxx&n=8`（または `map=earth`）で同じ地形の世界を共有できます。

## ファイル構成

```
index.html          画面
css/style.css       スタイル
js/core.js          乱数・ノイズ・名前生成・配色
js/world.js         地形生成（標高・気候・川・都市候補地）
js/sim.js           シミュレーション（経済・浸食・軍・攻城・外交・反乱・発展・驚異・道・世界の脅威）
js/battle.js        会戦（兵種と相性・布陣から追撃まで・援軍・奇襲・海戦・戦記）
js/poems.js         吟遊詩人の詩
js/commentary.js    実況モード・自動カメラ
js/book.js          歴史書
js/render.js        古地図風レンダラー
js/editor.js        大陸エディタ・地図の保存
js/audio.js         効果音
js/main.js          UI・入力・ゲームループ
js/earth-data.js    地球の陸地マスク（tools/build-earth.mjs で生成）
```

地球の陸地データは [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン、`world-atlas` パッケージ経由）から生成しています。
