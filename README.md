# 領土戦記 — Territory War

古地図（羊皮紙）風のマップ上で、NPCの国々が勝手に領土を奪い合う様子を**眺めるだけ**の観戦ゲームです。
ブラウザだけで動きます（ビルド不要・依存ライブラリなし）。

## 遊び方

`index.html` をブラウザで開くか、GitHub Pages で公開された URL にアクセスするだけ。

| 操作 | 内容 |
| --- | --- |
| ドラッグ / ホイール / ピンチ | 地図の移動・拡大縮小 |
| Space / 1〜5 | 一時停止 / 速度 (x0.5〜x8) |
| 国をクリック | 国情報（領土・兵力・同盟・戦争・安定度・歴史） |
| 神の手 | ☠️疫病 / 🌋天災 / ✨祝福 / 🔥反乱扇動 |

## 主な仕組み

- **地図**: ランダム大陸（シード指定で再現可）、地球、大陸エディタで自作した地図
- **大陸エディタ**: 陸と海を描くだけ。山・丘・森・砂漠・ツンドラ・川・都市は自動生成。首都位置の指定、ブラウザ保存、JSON 書き出し/読み込みに対応
- **国**: 2〜30か国。国名・都市名はファンタジー風に自動生成
- **領土の取り合い**: 国境が少しずつ動く「浸食」＋ 軍団が行軍・会戦・攻城する「侵攻」の両方
- **地形効果**: 山・丘・森は防御有利で進軍が遅い、川は渡りにくい、軍は船で海を越える
- **外交**: 宣戦布告・同盟・参戦・停戦・裏切り
- **都市・首都**: 都市が兵力を生み、首都が落ちると遷都して国が大きく揺らぐ
- **反乱・独立**: 大きくなりすぎた国、首都から遠い都市、征服されたばかりの土地で反乱が起き、旧国が復興することも。歴史は終わりません
- **表示**: 年代記ログ、勢力ランキング、領土シェア推移グラフ、地図上の国名ラベル、前線・進軍矢印
- **効果音**: WebAudio による合成音（🔊でON/OFF）

URL の `#map=random&seed=xxxx&n=8`（または `map=earth`）で同じ地形の世界を共有できます。

## ファイル構成

```
index.html          画面
css/style.css       スタイル
js/core.js          乱数・ノイズ・名前生成・配色
js/world.js         地形生成（標高・気候・川・都市候補地）
js/sim.js           シミュレーション（経済・浸食・軍・会戦・攻城・外交・反乱）
js/render.js        古地図風レンダラー
js/editor.js        大陸エディタ・地図の保存
js/audio.js         効果音
js/main.js          UI・入力・ゲームループ
js/earth-data.js    地球の陸地マスク（tools/build-earth.mjs で生成）
```

地球の陸地データは [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン、`world-atlas` パッケージ経由）から生成しています。
